Half the useful software in security started as a throwaway script someone
wrote to avoid doing a boring thing twice. If you wrote one to get through a
challenge — a decoder, a fuzzer, a parser, a bit of glue — it is worth
keeping.

Clean it up just enough that a stranger can run it: a name, a line saying what
it does, and how to invoke it. Then push it. Someone will hit the same problem
you did.

---

## Where They Go

The club's GitHub org is the home for member tools. If you are not sure a tool
is worth sharing, share it anyway — the bar is "did this help me," not
"is this production-grade."
