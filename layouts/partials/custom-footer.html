{{- /* Opt-in flags for the two page effects in assets/js/custom.js. Both are ON for the home page and section landing pages — the places people scan — and OFF for leaf pages. A section landing is a signpost you look at; a leaf page is a document you read, and neither a resolving heading nor falling glyphs behind body copy helps you read. "Section landing page" here means every _index.md render, nested ones included (/learn/, and also /learn/linux/). Hugo gives them all Kind == "section" and they all do the same job. Override per page with `scramble = true` / `rain = false` in front matter. isset is load-bearing — `false` and "not set" are different. */ -}} {{- $landing := or .IsHome (eq .Kind "section") }} {{- $scramble := $landing }} {{- if isset .Params "scramble" }}{{ $scramble = .Params.scramble }}{{ end }} {{- $rain := $landing }} {{- if isset .Params "rain" }}{{ $rain = .Params.rain }}{{ end }} {{- if or $scramble $rain }} {{- end }}
